# Projeto Amigo da Vizinhança
O projeto Amigo da Vizinhança é uma proposta de aplicação móvel desenvolvida em 
Flutter/Dart para a disciplina ACH2008 - Empreendedorismo, focada em resolver o problema 
do isolamento social e da ineficiência na gestão de pequenas necessidades diárias dentro de 
ambientes hiperlocais como condomínios e prédios. Atuando como uma mini-rede social 
validada, o aplicativo visa criar uma plataforma de cooperação, segurança e troca de 
serviços/itens entre vizinhos. O objetivo é transformar a vizinhança em uma comunidade 
autossuficiente e confiável, onde a solução para um problema (desde pedir uma ferramenta 
até alertas de segurança) está a apenas alguns toques de distância.

<br>

### Como Rodar?
Navegue até a pasta do projeto: ``cd neighborhood-helper``
<br> 
E depois execute isso:
```
flutter run -d chrome
```
Vai abrir um chrome a parte rodando a aplicação.

**Observações:** 
- Caso queira usar no celular basta tirar as flags `-d` e `chrome`.
- r → **Hot Reload**: Atualiza rapidamente o código da interface de usuário (layout, cores, texto)
sem perder o estado atual da aplicação.
- R → **Hot Restart**: Faz uma recompilação completa do código Dart e reinicia a aplicação 
do zero, perdendo o estado atual. Este comando é necessário após alterações estruturais 
profundas (ex: mudança na assinatura de um widget, atualização de rotas ou alteração em 
variáveis de estado global).
